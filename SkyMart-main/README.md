# 🌸 Wisteria Cart

**Where Shopping Blossoms**

Wisteria Cart is a modern and responsive e-commerce web application built with React and Tailwind CSS. It provides a smooth shopping experience with product browsing, filtering, cart management, and a beautiful Wisteria Bloom-inspired UI.

---

## 🚀 Features

- 🛍️ Browse products
- 🔍 Search products
- 🗂️ Filter by category
- 📦 Sort products
- 🛒 Add to Cart
- ➕ Increase/Decrease Quantity
- ❌ Remove Products from Cart
- 💳 Checkout
- 👤 User Authentication (Local Storage)
- 📱 Fully Responsive Design
- 🎨 Wisteria Bloom UI Theme
- ⚡ Fast React Performance

---

## 🛠️ Tech Stack

- React.js
- Tailwind CSS
- React Router
- React Context API
- React Hook Form
- Axios
- Framer Motion
- Lucide React
- React Hot Toast

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/wisteria-cart.git
```

Move into the project

```bash
cd wisteria-cart
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
